Seshat is an open source **runtime for AI agents**, written in Go. It runs the loop that turns a language model into something that can act: it sends your request to the model, executes the tools the model asks for, feeds the results back, and repeats until the task is done.

## Runtime and framework

Seshat is both. As a **runtime** you install it and use it as is: the terminal agent is ready after one command. As a **framework** you import it, add your own tools and providers, and ship your own agent.

## Three ways to use it

| Surface | Use it when | Start here |
|---|---|---|
| **Terminal** | You want an agent for your own work | [Quick start](/en/docs/getting-started/quick-start) |
| **Go SDK** | You are building an application with an agent inside | [Your first agent](/en/docs/getting-started/first-agent) |
| **gRPC server** | The agent must run as a service for other programs | [Installation](/en/docs/getting-started/installation) |

## What it gives you

- **Model choice.** Fifteen providers, from hosted APIs to local models with Ollama. Switch without changing your code.
- **Tools.** Files, shell, search, web and more, each guarded by permissions.
- **Memory of your work.** Sessions are saved locally and can be resumed.
- **Your rules.** Skills are Markdown files that teach the agent your conventions. MCP servers add external tools.

<Callout type="note" title="What it does not do">
Seshat does not host a model and does not send your files anywhere by itself. Your code and sessions stay on your machine; only the requests to the provider you chose leave it.
</Callout>
