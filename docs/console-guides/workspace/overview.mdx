# Overview

`/orgs/:id/workspace` — Organization → Workspace → Overview

## What it's for

The landing page for Workspace, the ungrouped nav item covering an
individual member's own self-service tools inside this organization -
distinct from every other group in the sidebar, which is admin
configuration. Three stat tiles (organizations you belong to, active
memberships, platform admin status) plus two quick-launch cards into
[Chat](./chat.mdx) and [Connections](./connections.mdx).

## How to use it

Nothing to configure here - it's a dashboard, not a settings page. Click
either card (or use the Overview/Chat/Connections tabs at the top) to
jump into the actual tool.

## See also

- [Chat](./chat.mdx) - validate a provider/MCP server/connector/knowledge
  corpus directly.
- [Connections](./connections.mdx) - connect your own accounts for the
  agent to act on your behalf.
