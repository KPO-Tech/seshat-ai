# Connections

`/orgs/:id/workspace/connections` — Organization → Workspace → Connections

## What it's for

Connect your own accounts so the workspace agent - both this org's
[Chat](./chat.mdx) and, once configured, Seshat Desktop - can act on your
behalf, with your own permissions. Deliberately separate from any
Knowledge source an admin sets up in
[Connectors](../integrations/connectors.mdx): that page's "Connected
sources" sync documents into a shared corpus (`knowledge_sync`, org-wide);
this page is self-service, per-member (`agent_action`) - each person
connects (or doesn't) independently, and one member's connection never
appears in anyone else's list.

28 connector kinds total, grouped by category (Storage & Files,
Productivity, Communication, Project & Issue Tracking, and more) - the
same kind catalog `@seshat/connector-catalog` feeds everywhere else this
console lists connectors, so a kind added there shows up here
automatically. Every kind here needs its OAuth app already registered by
an admin in Connectors → OAuth apps first; a kind with none configured
still shows a Connect button, it just fails immediately if clicked.

## How to use it

The search box filters the grid live by name or kind. "Connect" starts
that kind's real OAuth flow in a new tab; once authorized, the card
flips to show the connected account and a Disconnect action.
Reconnecting an account never affects anyone else on the team - the
0/28 counter at the top is your own connected count, not the
organization's.
