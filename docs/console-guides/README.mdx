# Seshat Console — user guide

What each page in the web admin console (`seshat-console`) is for and how
to use it. Written one sidebar group at a time, matching the redesign work
tracked in `docs/helps/console-ui-redesign.md` — a group's pages are
documented here once they've actually been reviewed and cleaned up, not
before.

One file per page, grouped into a folder per sidebar item that has more
than one tab. This keeps each file focused on a single page and makes the
set easy to drop onto a real docs site later — one file, one route.

Written as `.mdx` (Markdown, no JSX used yet) so it can grow into live
documentation and tutorials on the website later without a rewrite; every
file here also just reads as plain Markdown today.
