# Bundles

`/orgs/:id/automation/bundles` — Organization → Automation → Bundles

## What it's for

Packaging a selection of MCP servers, hooks, skill repos, and agent
presets into one portable manifest file — the actual scenario this
exists for is moving configuration between organizations (a template
setup, a client handoff), not something used day to day.

## How to use it

**Export**: name the bundle, pick which rows to include from each of the
four catalogs (checkboxes per section), download the resulting
`.seshatbundle.json`. **Import**: drag that file in, review what it
contains before committing to anything, then "Import into this
organization" — the result shows exactly what was created versus what
failed, per item, not a single pass/fail for the whole file.

Secrets never travel in a bundle — encrypted values (MCP server
env/headers, hook commands are plain text so those do) and anything
organization-specific (a connector's own OAuth account) are stripped from
the exported manifest; re-entering credentials after import is expected.
