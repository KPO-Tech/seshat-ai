# Jobs

`/orgs/:id/automation/jobs` — Organization → Automation → Jobs

## What it's for

Scheduled or on-demand automations — a prompt that runs on a trigger,
either in the cloud or on a specific registered [device](./devices.mdx).
This page only creates plain-prompt jobs; graph-based (dataflow) jobs
that chain multiple connector actions together are built in seshat-ui's
own graph editor (`/automation/new`), not here — that editor needs the
full window, not a column shared with the rest of the console.

## How to use it

Trigger is one of Cron (a schedule expression), Interval (every N
seconds), or One-off (a single future run-at time) — only the matching
field shows. Execution target is Cloud (runs on seshat-server itself,
needs a `provider:model` override) or Device (runs on a chosen
registered device, using whatever that device already has configured).

Row actions: run now (bypasses the schedule for a one-off test), pause/
resume, jump to that job's run history, edit, delete.
