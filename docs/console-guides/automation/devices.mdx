# Devices

`/orgs/:id/automation/devices` — Organization → Automation → Devices

## What it's for

The machines registered to run device-targeted jobs for this
organization — a connected desktop app (seshat-ui/seshat-backend), not a
generic "computer." A job with `execution_target: device` runs on
whichever device it names; a device has to exist here first.

## How to use it

"Register device" needs a name (and optionally platform/app version) and
issues a **one-time token** — shown once, never again, copy it
immediately. The local backend uses this token to authenticate its own
device-protocol calls (heartbeat, claiming a run). The "Jobs" column
links straight to that device's jobs, pre-filtered.

Revoking a device stops it from claiming new runs; it does not cancel
runs already in flight.
