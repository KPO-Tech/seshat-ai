# Agent Presets

`/orgs/:id/catalog/agent-presets` — Organization → AI Core → Agents & Skills

## What it's for

Organization-level agent personas — a name, a system prompt, a model, and
execution defaults, saved once and reused across every connected device
instead of every employee configuring their own from scratch. A
connected backend resolves this catalog alongside its own local presets.

## How to use it

"New preset" needs a slug (its stable identifier — lowercase,
hyphenated) and a system prompt at minimum; everything else has a
sensible default. "MCP servers" scopes this specific preset down to a
subset of the organization's full [MCP Servers](../mcp-servers.mdx)
catalog — leave it empty to give the preset access to nothing beyond the
built-in tools, not "everything approved."

"Allowed tools" / "Disallowed tools" and "Permission mode" / "Isolation"
control what the preset can do without confirmation versus what it must
always ask about — the same execution-safety controls available when
running an agent manually, just saved as a reusable default.
