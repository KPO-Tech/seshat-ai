# Skill Repos

`/orgs/:id/catalog/skill-repos` — Organization → AI Core → Agents & Skills

## What it's for

Organization-curated skill repository URLs — external collections of
reusable agent skills that a connected backend merges into its own local
catalog. Unconfigured, this organization falls back to the platform
default's repos, same pattern as Provider Settings and MCP Servers.

## How to use it

"Add skill repo" needs a name, the repository URL, and an optional
description. A repo inherited from the platform default (rather than
added here) shows "Inherited" instead of edit/delete controls — it isn't
this organization's own row to change.
