# Network Diagnostics

`/orgs/:id/integrations/network-diagnostics` — Organization → Integrations → Integrations → Network Diagnostics

## What it's for

Self-service connectivity troubleshooting for enterprise IT — checks
**this server's own** outbound reachability to its dependencies (the
SMTP relay, any enabled SSO provider's endpoints), not this device's
path to the server. It runs on demand only, never automatically, since
it makes real outbound network calls.

## How to use it

"Run diagnostics" checks whatever is actually configured for this
organization — nothing to check means no SMTP relay and no enabled SSO
providers exist yet. Each check expands into its individual steps (DNS,
TCP connect, TLS, ...); a failed step often carries a suggestion and who
should act on it (your network admin, your IT/security team, or Seshat
support).
