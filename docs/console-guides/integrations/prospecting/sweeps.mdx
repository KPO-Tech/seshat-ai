# Sweeps

`/orgs/:id/prospecting/sweeps` — Organization → Integrations → Prospecting → Sweeps

## What it's for

Business-discovery sweeps over a geographic area — finding real
businesses (via Google Places) matching given sectors, for outbound
prospecting. Needs [Settings](./settings.mdx)'s own Google Places API
key configured first.

## How to use it

"New sweep" takes a free-text area (geocoded server-side, e.g. "Lyon,
France"), a country, optional sectors, a search radius, and a cap on how
many grid tiles one call processes. A sweep that hits that cap comes
back `partial` — "Continue" picks up where it left off rather than
starting over, using the sweep's own stored area/parameters (nothing new
to re-enter). "View businesses" opens the results with filters (sector,
minimum reachability score, has-phone).
