# Prospecting Settings

`/orgs/:id/prospecting/settings` — Organization → Integrations → Prospecting → Settings

## What it's for

This organization's own Google Places API key, the credential
[Sweeps](./sweeps.mdx) runs on. Strictly bring-your-own-key — unlike
most other credential pages in this console, there is no platform
default to fall back to.

## How to use it

"Configure" needs the API key and a daily call cap (the maximum real
Google Places API calls allowed per day, across every sweep in this
organization combined - a cost guardrail, not a per-sweep limit).
