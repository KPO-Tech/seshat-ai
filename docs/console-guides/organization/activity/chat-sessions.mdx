# Chat Sessions

`/orgs/:id/activity/chat-sessions` — Organization → Activity → Chat Sessions

## What it's for

Admin visibility into how much the organization's members are using
Workspace Chat — the personal AI chat every member has in their own
Workspace — **metadata only**: who, when, the session title, and how many
messages.

The actual conversation content is never fetched here and stays private
to the member who wrote it; they're the only one who can open a
session's real messages, from their own Workspace → Chat.

## How to use it

Sort by "Last active" or "Started." Nothing to click into — it's a
read-only usage log.
