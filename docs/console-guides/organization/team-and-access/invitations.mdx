# Invitations

`/orgs/:id/team/invitations` — Organization → Team & Access → Invitations

## What it's for

Tracking *pending* access, as opposed to
[Memberships](./memberships.mdx), which only ever lists people who
already have access. An invitation is a promise of access by email; it
becomes a membership once accepted.

## How to use it

"Invite" needs an email, a role, and how many days before it expires (7
by default, up to 90).

Use the status tabs (All / Pending / Accepted / Revoked / Expired) to
filter the list. A still-pending invitation can be revoked with the stop
icon; accepted, revoked, and expired ones have nothing left to do.
