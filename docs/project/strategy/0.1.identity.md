# Seshat — Identité de marque

Pas dans les exports PDF — un document de référence à part, pour trancher et suivre l'identité visuelle. Tout ce qui suit vient directement du code réel de `seshat-ui` et `seshat-console` (chemins et lignes cités), pas inventé — même discipline que le reste de ce document set.

## Palette de couleurs

## Typographie

Déclarée dans `tokens.css` :
```
--font-sans: 'Plus Jakarta Sans', 'Inter', -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, sans-serif;
--font-serif: 'Georgia', serif;
```
Monospace (blocs de code) : `ui-monospace, 'SF Mono', 'Cascadia Mono', Menlo, Consolas, monospace`.

**Écart intention/implémentation trouvé :** aucun `@font-face`, aucun lien Google Fonts, aucun fichier `.woff`/`.woff2`, aucune dépendance `@fontsource/*` nulle part dans `seshat-ui` ni `seshat-console`. "Plus Jakarta Sans" est déclarée comme police prévue mais n'est jamais réellement chargée — l'app retombe silencieusement sur les polices système (Segoe UI sous Windows) sauf si la police est installée sur la machine par hasard. Pire, `seshat-ui/globals.css` fait retomber le corps de texte de base directement sur la pile système, sans même essayer Jakarta/Inter.

## Logo

- **Logo actuellement utilisé dans l'app :** `seshat-ui/public/seshat.svg` — 512×512, un seul path, `fill="rgba(0,0,0,1)"` (noir plein). Rendu via le composant `NexusLogo.tsx`, utilisé dans la sidebar, l'écran À propos, l'auth, les paramètres, etc.
- **Incohérence trouvée :** le commentaire dans `NexusLogo.tsx` dit explicitement *"Use only the orange logo for both themes"* — mais le composant pointe vers `seshat.svg`, qui est noir, pas orange.
- **Anciens logos, présents mais plus utilisés nulle part dans le code :** `nexus.svg` et `nexus_dark.svg` (contenu identique, deux paths orange `#EF7C2F`, motif d'aile/ruban abstrait) et `nexus.png`. Vraisemblablement un ancien design de logo remplacé par `seshat.svg`, jamais nettoyé du dossier assets.
- **Logo console :** `seshat-console/public/seshat.png` — favicon + page d'authentification.
- **Logo README :** `docs/images/seshat.png`, référencé dans le `README.md` racine.
- **Asset isolé, sans rapport :** `seshat-ui/public/Kittl_Medusa.svg` existe mais n'est référencé nulle part — probablement un import de design oublié.
- **Icône d'application :** aucune icône personnalisée configurée dans `electron-builder` (`seshat-ui/package.json`) — l'app packagée utilise l'icône par défaut d'Electron, pas une icône SeshatOS.

## Un problème de nommage sous-jacent

Le produit s'appelle **SeshatOS** / **Seshat** en externe — titre de fenêtre, README, favicon, nom de package. Mais le code interne utilise encore **"Nexus"** partout : le pont IPC `window.nexus`, le composant `NexusLogo`, les fichiers `nexus.svg`/`nexus_dark.svg`/`nexus.png`, et même l'en-tête du fichier `tokens.css` lui-même (*"NEXUS DESIGN TOKENS"*).

Tout indique un ancien nom de produit ("Nexus") jamais complètement renommé en interne après le rebranding vers "Seshat". C'est le même genre de résidu que la confusion Companion/Company Assistant trouvée plus tôt dans `4.product.md` — un nom qui traîne dans le code après une décision de renommage prise ailleurs.

## Ton déjà déclaré dans le code

Le fichier `tokens.css` se décrit lui-même : *"Claude-inspired premium palette — warm neutrals, tinted grays, soft tonal layering."* Et : *"Type scale — compact, Claude Desktop-density target."*

`seshat-console/theme/tokens.ts` reprend la même intention : *"Warm neutrals, a single orange brand accent, warm off-white text — same identity as the desktop app, not stock Ant Design blue on a white canvas."*

Aucun des commentaires du code n'emploie littéralement "anthracite chaud" comme expression — mais "warm" revient constamment comme descripteur voulu pour la famille de gris/neutres, et `#2F2E34` est précisément un gris anthracite. "Anthracite chaud" est donc une paraphrase fidèle de l'intention, pas une citation du code.
