Logo du runtime seshat

Logo officiel du runtime open source seshat : la rosette dans une fenêtre de terminal (retenu le 2026-10-06).

seshat est le runtime d'agents open source (Go, SDK, CLI, TUI, gRPC), la fondation de SeshatOS et de SeshatCloud. Son logo part du logo principal avec une variation tournée vers les développeurs, vue surtout dans un README et dans un terminal. Toutes les pistes partent du style reseau sans la tige. Retenu le 2026-10-06 : Sh2, la rosette dans une fenêtre de terminal.
