Identité visuelle Seshat AI

Un point d'entrée pour tout le kit : logo, couleurs, thèmes, icônes des apps. Tout est généré par python build.py à partir de quelques constantes.

État des décisions

  • Logo : styles v2 emblem et reseau retenus (l'étoile v1 est gardée), deux palettes conservées.
  • Thèmes du desktop : les trois versions conservées, aucune tranchée.
  • Icônes des apps : K1 pour Knowledge, A2 pour Automation. Les autres apps plus tard.
  • Couleurs : alignées sur le desktop (charbon #2F2E34, orange #EF7C2F, papier #F6F1EA).
  • À faire : vectoriser le logotype ; exports PNG ; recherche INPI.
