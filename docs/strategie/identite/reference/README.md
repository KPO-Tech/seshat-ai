# reference/

Les logos **dessinés à la main en SVG** avant la réécriture du kit. Ils ne sont plus la source : le kit (`../kit/`) les génère. Ils restent ici comme **fichiers de référence** : `tests/test_kit.py` vérifie que le générateur dessine exactement les mêmes chemins, cercles et textes.

| Dossier | Contenu |
| --- | --- |
| `svg/` | Les SVG d'origine par produit (runtime, cloud, seshatos, knowledge, kpo-tech). |
| `png/` | Deux logos livrés en PNG seulement (Knowledge, KPO-Tech). |
| `boards/` | Les cinq planches de marque, utiles pour valider les marques sans original SVG (Automation). |

Ne pas modifier ces fichiers : si un logo change, on change le kit, puis on décide si la nouvelle version devient la référence.
