## Brand & Style

This design system embodies the ethos of institutional intelligence, epistemic rigor, and categorical reliability. Designed for mission-critical enterprise environments, intelligence synthesis, and large-scale enterprise graph exploration, the visual language balances surgical precision with calm, authoritative clarity.

The aesthetic philosophy draws upon:
- **Systematic Modernism:** Strict structure, high-density data legibility, and architectural hierarchy over decorative ornament.
- **Epistemic Authority:** Crisp lineation, discrete status taxonomy, and micro-metric clarity that signal infallible operational integrity.
- **Quiet Depth:** Balanced surface layering through subtle neutral tones, eliminating visual fatigue during continuous analytical workflows.

The interface evokes unwavering trust, cognitive control, and clarity amid immense organizational complexity.

## Colors

The palette establishes a high-density, multi-dimensional semantic taxonomy for governance, validation, and complex node categorization.

### Core Foundation
- **Canvas Base (`surface-ground`):** `#F8FAFC` (Slate 50) for primary application frame.
- **Surface Elevation 1 (`surface-base`):** `#FFFFFF` (Pure White) for cards, data grids, and reading panes.
- **Surface Elevation 2 (`surface-muted`):** `#F1F5F9` (Slate 100) for toolbars, inactive tabs, and grouped containers.
- **Border Structural:** `#E2E8F0` (Slate 200) for standard layout boundaries.
- **Border Crisp / Interactive:** `#CBD5E1` (Slate 300) for focus targets, dividers, and cell demarcations.

### Typography & Content Tokens
- **Text Primary:** `#0F172A` (Slate 900) — dominant text, active records, and numerical headers.
- **Text Secondary:** `#475569` (Slate 600) — structural metadata, field labels, and contextual markers.
- **Text Muted:** `#94A3B8` (Slate 400) — disabled targets, non-actionable timestamps, and graph hulls.

### Epistemic & Domain Semantics
- **Intellectual Core (Primary):** `#1D4ED8` (Cobalt Blue) / Hover `#1E40AF` / Tint `#EFF6FF` — system navigation, primary execution, and logical roots.
- **Verified Knowledge (Confidence High):** `#047857` (Emerald 700) / Tint `#ECFDF5` / Stroke `#A7F3D0` — verified truth records, policy certifications, and high-confidence AI synthesis.
- **Obsolescence & Advisory (Warning):** `#B45309` (Amber 700) / Tint `#FFFBEB` / Stroke `#FDE68A` — deprecated documentation, stale graph edges, and pending human review.
- **Contradiction & Critical Risk (Destructive):** `#B91C1C` (Crimson 700) / Tint `#FEF2F2` / Stroke `#FECACA` — logical paradoxes, policy violations, and critical security classifications.
- **Knowledge Graph & Schema (Entity Accent):** `#7C3AED` (Violet 700) / Tint `#F5F3FF` / Stroke `#DDD6FE` — conceptual ontologies, semantic triples, and entity relations.

## Typography

The typographic hierarchy accommodates high semantic density while preserving scanning speed across vast document sets and tabular reports.

- **Primary Structure (`Plus Jakarta Sans`):** Selected for structural headers, contextual side-drawers, and executive metrics. Provides modern character without compromising institutional gravity.
- **Analytical Reading & Operations (`Inter`):** Applied to document analysis views, body text, form elements, and standard table cells. Features high x-height and exceptional micro-legibility at 12px and 14px.
- **Technical & Cryptographic Context (`JetBrains Mono`):** Dedicated to node IDs, confidence thresholds, cryptographic hashes, schema expressions, and ISO timestamps.
- **Tabular Figures:** All numeric data, including revision counts, confidence indices, and token metrics, mandate `font-variant-numeric: tabular-nums` to ensure exact column alignment.

## Layout & Spacing

This design system uses a precise 4px baseline grid tailored for data-dense analytics and workbench workflows.

### Grid Architecture
- **Application Workbench:** A multi-panel fluid layout utilizing a fixed `17.5rem` (280px) left navigational rail, a contextual collapsible schema filter panel (240px to 320px), and a responsive canvas workspace.
- **Data Densities:** Standard row heights settle at `2.25rem` (36px) for compact tabular matrices, expanding to `3rem` (48px) for document inspection tables containing governance status tags.
- **Panels & Canvases:** Primary workspace gutters scale dynamically:
  - Mobile/Tablet Breakpoints (under 1024px): Collapses navigation to icon-only docked drawers; padding sets to `space-md` (`0.75rem`).
  - Desktop (1024px to 1440px): Standard enterprise density with `space-lg` (`1rem`) container gaps.
  - Ultrawide (1441px+): Workspace limits single document view columns to `52rem` (832px) for optimal line-length reading, while data tables scale to 100% fluid container width.

## Elevation & Depth

Visual hierarchy is communicated predominantly through precise structural outlines, planar surface shifts, and minimal ambient shadows.

- **Planar Stacking:** Background sits at `surface-ground` (`#F8FAFC`). Core work canvases use `surface-base` (`#FFFFFF`). Overlaid flyouts, query toolbars, and contextual inspectors reside at `surface-base` with explicit `1px` structural borders (`#E2E8F0`).
- **Low-Contrast Outlines (Ghost Framing):** Every container, card, and popover enforces a `1px` border. In active or focused states, borders step up from `#E2E8F0` to `#CBD5E1` or the semantic primary `#1D4ED8`.
- **Ambient Shadow Metrics:** Shadows are subdued and tinted with slate to prevent visual distraction:
  - *Resting Cards / Tables:* Zero shadow; separation handled via `#E2E8F0` borders.
  - *Context Menus / Dropdowns:* `0 4px 12px -2px rgba(15, 23, 42, 0.08), 0 2px 6px -1px rgba(15, 23, 42, 0.04)`.
  - *Critical Governance Modals / Entity Inspectors:* `0 20px 25px -5px rgba(15, 23, 42, 0.1), 0 8px 10px -6px rgba(15, 23, 42, 0.04)`.

## Shapes

The design system maintains a calibrated, low-radius architectural form factor (Level 1: Soft).

- **Global Corners (`0.25rem` / 4px):** Applied to form fields, utility buttons, compact micro-badges, data table cells, and context menus. This geometry reinforces high density and computational accuracy.
- **Containers & Flyouts (`0.5rem` / 8px):** Structural cards, modal dialogues, graph property sheets, and code panels adopt `rounded-lg`.
- **Strict Exceptions:** Completely round (`9999px`) styling is limited strictly to circular status confidence indicators and user avatars. Pill shapes are barred from structural buttons, badges, and chips to preserve institutional formality.

- **Verified Status:** Surface `#ECFDF5`, text `#047857`, border `1px solid #A7F3D0`. Includes a `4px` solid emerald dot prefix.

- **Knowledge Entity (Entity / Node Type):** Surface `#F5F3FF`, text `#7C3AED`, border `1px solid #DDD6FE`.

### Tabular Data Grids
- **Header:** Height `2rem`, background `#F8FAFC`, border-bottom `1px solid #CBD5E1`. Text uppercase `label-sm`, color `#475569`.
- **Rows:** Alternating hover highlight `#F8FAFC`. Active row selection tint `#EFF6FF` with a `2px` solid `#1D4ED8` left indicator line. Cell dividers `1px solid #E2E8F0`.

### Form Fields & Inputs
- **Base Input:** Height `2rem` (32px), background `#FFFFFF`, border `1px solid #CBD5E1`, text `body-md`, radius `0.25rem`.
