v2.4 Spec

Variables are immutably injected into execution runtimes. Call them anywhere in prompt templates, condition nodes, or TypeScript sandboxes.

Agent Condition Node 
// In Prompt or Expression Node:
if ($node.invoiceTotal > $vars.MAX_AUTONOMOUS_AMOUNT) {
  return $gate.requireHumanApproval({
    channel: $vars.FINANCE_ESCALATION_CHANNEL
  });
}

Note on Sensitive Secrets

Variables are stored in plaintext runtime configuration. For OpenAI API keys, database credentials, or signing tokens, navigate to Workspace → Credentials to ensure AES-256 vault encryption and strict RBAC audit access.
