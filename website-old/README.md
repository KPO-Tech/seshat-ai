# Seshat Website

This package contains the public marketing website for Seshat.

The messaging model is intentionally split:

- the homepage stays narrow and credible
- the enterprise page speaks to deployment, governance, and rollout
- the docs carry the broader open-source vision

## Positioning

Seshat is presented here as:

> an open-source, self-hosted, multi-provider agent platform for organizations that need governed execution and real operational control.

That means the website should emphasize:

- permissions
- auditability
- self-hosting
- provider portability
- runtime + platform layering
- deployment and integration reality

It should avoid turning the homepage into a grand manifesto about every possible future surface.

## Content Model

- `/` = narrow wedge, product clarity, proof
- `/services` = enterprise deployment and governed workflows
- `/docs` = architecture, runtime concepts, open-source direction, contribution

## Notes

The larger ambition of Seshat still matters, but it belongs primarily in docs, README files, contribution pages, and long-form writing rather than in the homepage hero.
