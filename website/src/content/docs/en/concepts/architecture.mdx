Seshat is organised in layers. Each one only depends on the layers below it, so you can use the top of the stack as an end user or reach down and replace a piece.

## The query loop

Every request goes through the same cycle:

<Flow items={[
  { icon: 'chat-circle-text', label: 'Messages' },
  { icon: 'robot', label: 'Model' },
  { icon: 'wrench', label: 'Tool calls' },
  { icon: 'shield-check', label: 'Permissions' },
  { icon: 'arrows-clockwise', label: 'Repeat' },
]} />

1. Your message and the conversation so far are sent to the model.
2. If the model answers with text only, the loop ends.
3. If it asks for tools, Seshat checks permissions, runs them, and adds the results to the conversation.
4. The model is called again with those results, until it has nothing left to do.
