Seshat ships as a single binary. Pick the route that fits you: a one-line install script for end users (a shell script on Linux and macOS, a PowerShell script on Windows), the Go toolchain for developers, or a source build if you want to hack on it.

<Callout type="note" title="Platforms">
There is an install script for **Linux** and **macOS** and one for **Windows**, all on `amd64` and `arm64`. The terminal interface is used on Windows Terminal; other Windows setups have had less testing.
</Callout>

## Install with the script on Linux and macOS

<Steps>

1. **Run the installer.**

   ```bash
   curl -fsSL https://raw.githubusercontent.com/KPO-Tech/seshat-runtime/main/scripts/install.sh | bash
   ```

2. **Reload your shell** if the installer asks you to, or open a new terminal. The installer adds `~/.local/bin` to your `PATH`.

3. **Check the installation.**

   ```bash
   seshat version
   ```

</Steps>

### What the script does

- Detects your system and downloads the matching binary from the GitHub release.
- Verifies its SHA-256 checksum, and stops if it does not match.
- Installs it in `~/.local/bin` and adds that folder to your shell profile if needed.
- Prepares the runtime folder `~/.config/seshat-cli/` (it follows `XDG_CONFIG_HOME` when set). The database and your sessions are created on first run.

### Options

```bash
# Pin a specific version
VERSION=v1.5.0 bash <(curl -fsSL https://raw.githubusercontent.com/KPO-Tech/seshat-runtime/main/scripts/install.sh)

# Install somewhere else
INSTALL_DIR=/usr/local/bin bash <(curl -fsSL https://raw.githubusercontent.com/KPO-Tech/seshat-runtime/main/scripts/install.sh)
```

## Install on Windows

<Steps>

1. **Open PowerShell** and run the installer. It does not need administrator rights.

   ```powershell
   irm https://raw.githubusercontent.com/KPO-Tech/seshat-runtime/main/scripts/install.ps1 | iex
   ```

2. **Open a new terminal** if `seshat` is not found: the installer adds its folder to your user `PATH`, which only new terminals read.

3. **Check the installation.**

   ```powershell
   seshat version
   ```

</Steps>

### What the Windows script does

- Picks the build for your processor (`amd64` or `arm64`) and downloads it from the GitHub release.
- Verifies its SHA-256 checksum, and stops before writing anything if it does not match.
- Installs `seshat.exe` in `%LOCALAPPDATA%\Programs\seshat` and adds that folder to your user `PATH`.
- Installs [ripgrep](https://github.com/BurntSushi/ripgrep) with winget, scoop or choco when it is missing: the `glob` and `grep` tools need it. If none of them is available, the script tells you where to get it.
- Uses the runtime folder `%APPDATA%\seshat-cli\`. The database and your sessions are created on first run.

### Windows options

Set these variables in the same PowerShell session, before the command.

```powershell
# Pin a specific version
$env:SESHAT_VERSION = "v1.9.0"

# Install somewhere else
$env:SESHAT_INSTALL_DIR = "C:	ools\seshat"

# Do not try to install ripgrep
$env:SESHAT_SKIP_RIPGREP = "1"
```

To make `shift+Enter` insert a new line in Windows Terminal or VS Code, run `seshat terminal-setup`.

## Install with the Go toolchain

You need **Go 1.26 or later**.

```bash
go install github.com/KPO-Tech/seshat-runtime/cmd/cli@latest
```

## Build from source

```bash
git clone https://github.com/KPO-Tech/seshat-runtime
cd seshat-runtime
make build
```

This produces two binaries in `bin/`:

| Binary | Purpose |
|---|---|
| `bin/seshat` | Interactive terminal agent: chat, run tools, manage sessions |
| `bin/seshat-grpc` | gRPC server, to embed Seshat in a larger system |

## Use it as a library

To embed the runtime in your own Go application, add the SDK to your module:

```bash
go get github.com/KPO-Tech/seshat-runtime@latest
```
